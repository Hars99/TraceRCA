# TraceRCA Visual Assets

This directory contains visual documentation and UI captures for the TraceRCA project.

## Suggested Screenshots

To capture complete visual evidence for presentations and documentation, record the following screenshots:

1. `dashboard-overview.png` — Main dashboard showing active incidents, key metrics, and replay verification summaries.
2. `incident-investigation.png` — Incident detail page (`/incidents/<id>`) displaying the chronological telemetry timeline and causal breakdown (Trigger, Amplifier, Recovery).
3. `verified-replay.png` — Replay comparison page (`/replays/<id>`) illustrating baseline vs candidate side-by-side metrics and the verified status badge.
4. `bob-investigation.png` — IBM Bob interface running `/tracerca-incident-investigation <id>` with structured evidence output.
5. `bob-remediation.png` — IBM Bob interface executing `/tracerca-verified-remediation <id>` with replay execution and verification verdict.
